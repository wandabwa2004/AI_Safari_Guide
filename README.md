# 🧠 AI Safari Guide

Welcome to **AI Safari Guide** — a unique AI-powered storytelling companion that brings the African wilderness to life through intelligent conversation and immersive guidance.

This project uses large language models and modern Python tooling to simulate a safari guide powered by AI. Designed to be interactive, visual, and user-friendly, it’s perfect for educational experiences, storytelling, or even conceptual travel demos.

---

## 🚀 Features

- Conversational AI guide trained for safari-like storytelling  
- Streamlit interface for interactive use  
- Real-time environment descriptions powered by `openai`  
- Rich terminal outputs for debugging or CLI interaction  
- Easily extensible for other types of guides (e.g., museums, historical sites)

---

## 📦 Installation

1. **Clone the repository:**

```
git clone https://github.com/wandabwa2004/AI_Safari_Guide.git
cd AI_Safari_Guide
```

2. **Create a virtual environment (optional but recommended):**

```
python3.10 -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
```

3. **Install dependencies:**
   
```pip install -r requirements.txt```

🧪 Running the App

Launch the Streamlit app the usual way ... `streamlit run ai_safari_agent.py `
